visuals/reference/
==================

Standalone reference charts. Nothing in here is verse-keyed, so
build_manifest.py does not index it (it only walks visuals/<Book>/<ch>/ and
the flat visuals/ root) and the web app does not serve it automatically.
These are wall charts to open on their own, and to crop from when a passage
needs a piece of one.


Old_Testament_family_tree.svg
-----------------------------
One contiguous family tree of the whole Old Testament, rooted at Adam.
26,486 x 15,464 px, ~1.3 MB, 1,268 people and houses.

Generated by      generate_ot_family_tree_svg.py
Data              chronicles_tree.py   (the 1 & 2 Chronicles spine)
                  ot_grafts.py         (everything else that joins to it)
Names             World English Bible, unmodified

Open the .svg directly in a browser to zoom and scroll it natively, or open
Old_Testament_family_tree.html for the viewer, which adds drag-to-pan,
wheel-zoom, and a name search that flies to each hit in turn.

Reading it:
  solid line     father to son, as the text states it
  dashed + bead  a join the text implies but does not state; the note on the
                 box says what the inference is
  doubled line   a wife, and the line reckoned through her
  gold line in   a cross-reference: this person is named somewhere else on
  a box          the sheet, and the line says how. Written inside both
                 boxes, never floating between them. Pairs that end up near
                 each other are tied by a gold arc as well.
  gold box       a king            jade box   a priest or Levite
  rose box       a woman           grey box   a house or company
  small number   the generation from Adam (bottom right of each box)

To rebuild:  python generate_ot_family_tree_svg.py
To audit the tree without drawing it:  python chronicles_tree.py
